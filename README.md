# Nithin Athrapulikkal

Personal site for my software engineering work, projects, and writing. It is built with Astro and MDX and deployed on Netlify.

## Develop

```sh
pnpm install
pnpm dev
```

Create a production build with `pnpm build`.

## Content

- `src/content/other/about.mdx` — homepage introduction
- `src/content/posts/` — blog posts
- `src/content/projects/` — project pages
- `src/content/work.json` — work history
- `src/content/info.json` and `src/content/socials.json` — homepage details and links
- `src/styles/` — site styling
